Featured Work

Every project starts with a challenge and delivers real value.

Campus Express

Smart campus food marketplace connecting students with vendors.

Challenge

Campus food vendors lack a digital presence. Students waste time walking around campus looking for food, with no way to compare menus, prices, or reviews before committing.

Solution

A platform for vendor discovery, menu browsing, search, reviews, and direct ordering — all integrated with WhatsApp so students can order without downloading another app.

Value

Students save time making food decisions. Vendors gain digital visibility and a direct channel to their customers. The campus food experience becomes efficient and transparent.

HTML CSS JavaScript PHP
Functional prototype with vendor listings, search, and ordering workflow

LAPOK Ventures

Digital platform for a Coca-Cola bulk distribution business.

Challenge

A bulk distribution business relied on phone calls and paper catalogs. Wholesale customers couldn't browse products independently, compare options, or place orders outside business hours.

Solution

A digital platform that showcases the full product catalog, enables easy browsing and search, and streamlines the ordering experience — available 24/7 for wholesale customers.

Value

Customers get instant access to products and pricing without calling. The business reduces order errors and operates more efficiently. The brand looks professional and modern.

HTML CSS JavaScript
Platform concept with improved product presentation and ordering flow

Sports / Match Platform

Web-based platform exploring football data and match information.

Challenge

Fans and analysts need a clean, centralized way to access football fixtures, match data, and statistics — but information is scattered across multiple apps and websites with inconsistent formats.

Solution

A web platform that integrates football APIs to display fixtures, match information, and real-time data in one intuitive, easy-to-navigate interface.

Value

Users get all football data in one place without juggling multiple apps. The clean interface makes it easy to find what matters — upcoming matches, results, and stats at a glance.

HTML CSS JavaScript REST API
Working prototype with API integration and real-time match display

Inventory Management System

Business system for managing products, stock, and alerts.

Challenge

Small businesses struggle with manual inventory tracking — using spreadsheets or paper logs — leading to stockouts, overstock, missed orders, and wasted time reconciling records.

Solution

A system to manage products, stock levels, users, receipts, and low-stock alerts with a clean dashboard interface — everything in one place with real-time visibility.

Value

Business owners know exactly what's in stock at any moment. Low-stock alerts prevent stockouts before they happen. Receipts and user tracking create accountability and reduce errors.

PHP MySQL HTML CSS
Functional system with CRUD operations, alerts, and receipt management
